# Автоматизированная информационная система управления интернет-магазином автозапчастей

## Описание проекта
Веб-приложение для автоматизации бизнес-процессов интернет-магазина. Система обеспечивает полный цикл товарного учета автозапчастей, обработку клиентских заказов, контроль движения складских запасов и формирование детализированной аналитической отчетности.

Проект разработан в рамках курсовой работы по дисциплине "Базы данных" с соблюдением строгих архитектурных ограничений: отказ от ORM, написание прямых SQL-запросов и запрет на использование тяжелых веб-фреймворков (используется микрофреймворк FastAPI).

## Стек технологий
* **База данных:** PostgreSQL 15+
* **Серверная часть:** Python 3, FastAPI, `psycopg2-binary` (прямые SQL-запросы без ORM)
* **Клиентская часть:** HTML, CSS, JavaScript (Vanilla)
* **Форматы обмена данными:** JSON, XML, CSV
* **Отчетность:** Генерация документов в форматах Word (`python-docx`), Excel (`openpyxl`), PDF (`reportlab`)

## Реализованный функционал
* **Аутентификация и безопасность:** Раздельный доступ для клиентов и администраторов с защитой от SQL-инъекций (параметризованные запросы `%s`) и хешированием паролей (bcrypt). JWT авторизация.
* **Каталог и корзина покупок:** Поиск, сортировка и добавление автозапчастей в корзину с учетом остатков.
* **Управление заказами:** Отслеживание статусов, ведение истории заказов, транзакционное создание заказа с автоматическим списанием складских запасов. Фиксация цен на момент покупки.
* **Импорт и экспорт данных:** Загрузка и выгрузка каталогов/прайс-листов товаров в форматах JSON, XML и CSV.
* **Аналитика и отчетность:** 
  * Выгрузка товарной накладной по каждому заказу в PDF.
  * Формирование аналитических сводок по продажам в Excel.
  * Создание агрегированного отчета для руководителя в Word (сводка по заказам, выручке и топ-товарам).

## Установка и запуск
1. Клонируйте репозиторий:
   `git clone [ссылка_на_репозиторий]`
2. Создайте базу данных в PostgreSQL:
   `CREATE DATABASE autopartsdb;`
3. Выполните DDL-скрипт и заполнение тестовыми данными:
   `psql -U postgres -d autopartsdb -f database/schema.sql`
   `psql -U postgres -d autopartsdb -f database/seed.sql`
4. Создайте виртуальное окружение Python и установите зависимости:
   `pip install -r requirements.txt`
5. Настройте параметры подключения к БД в файле `.env` (при необходимости измените `DB_PASSWORD`):
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=autopartsdb
   DB_USER=postgres
   DB_PASSWORD=1234
   ```
6. Запустите сервер:
   `uvicorn app.main:app --reload`
   Приложение будет доступно по адресу `http://localhost:8000/`.

## Структура базы данных
База данных спроектирована в 3-й нормальной форме и включает следующие основные сущности:
* `Role` и `"User"` — управление доступом.
* `Product` — товарная номенклатура автозапчастей.
* `Cart` — корзина пользователей.
* `"Order"` и `OrderItem` — транзакционные данные заказов с фиксацией цены на момент покупки.
* `"Transaction"` и `DeliveryData` — финансовые операции и логистика.
